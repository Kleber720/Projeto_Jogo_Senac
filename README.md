> **Estudos e tutoriais:** este repositório reúne exercícios, prática de curso ou acompanhamento de tutoriais. Não faz parte dos quatro projetos principais do portfólio.

Projeto de jogo desenvolvido no contexto do Senac Santana. Este repositório é um fork de [victorprogramer121/Projeto_Jogo_Senac](https://github.com/victorprogramer121/Projeto_Jogo_Senac).

## Conteúdo

- Menu inicial e tutorial.
- Fases, personagens e plataformas.
- Lógica de jogo em JavaScript.
- Estilos, imagens e recursos visuais.

## Como visualizar

Sirva a pasta por um servidor local, como o Live Server do VS Code, e abra [`Marcacao/index.html`](Marcacao/index.html).

## Organização

- `Marcacao/` — páginas do jogo.
- `Script/` — lógica e menus.
- `Data/` — dados das fases.
- `Entitys/` — personagens e plataformas.
- `Estilo/` e `Imagem/` — estilos e recursos visuais.
- [Guia de estilo](GUIA-DE-ESTILO.md) — referência visual.
